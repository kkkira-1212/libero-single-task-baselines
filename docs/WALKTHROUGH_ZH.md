# 明早一起捋：这份仓库交付了什么

## 先用一分钟讲清

我们用LIBERO提供的50条专家示范，训练四种作者代码基础上的模型，让它们完成“拿汤罐放进篮子”。40条示范用于训练、10条用于验证；再让每个训练好的模型在20个初态下自己操作机器人。仓库交付的是单任务适配、结果与证据、主要问题的分析和运行说明。

## 你自己读代码的顺序

1. `README.md`：先确认范围、结果和局限，不背jobID。
2. `configs/baselines_causal/dp_seed0.json`：找训练更新次数、数据标签约定、执行步数和评估初态。
3. `adapters/libero_sequence.py`和`adapters/libero_causal_contract.py`：看模型输入哪些历史、目标动作从哪一帧开始。存储的obs[t]在action[t]之后，下一条命令从t+1开始。
4. `adapters/dp_model.py`：找作者模型构造和训练数据归一化。
5. `experiments/dp_run.py`：分别找train和evaluate。训练从示范学习；evaluate让模型自己改变环境，再接收新观测。查看execution_horizon如何控制多久再规划。
6. `results/runs.json`选一个DP条目，再打开它的evidence路径：成功率必须能数回每个回合。
7. `experiments/a2a_confirm_eval.py`：找settle_gripper_command，只在预热改变夹爪命令，模型权重不变。比较原始条件和诊断条件。

## 需要能自己回答

- 我们使用作者实现，适配层负责什么？输入图像/机器人状态，输出控制器命令；没有从零重写四个算法。
- 官方示范50条与评估20次有何不同？前者是学习材料；后者是模型自己控制机器人的完整测试。
- 为什么loss下降还要跑仿真？专家状态附近预测得像，不保证模型自己的误差累积后仍能成功。
- 两个seed是什么？两个独立训练模型，初始化与抽样随机性不同；训练GPU也不完全相同，不能把结果差别全部归因为seed。
- DP执行1步和A2A单flowstep有何不同？前者改变物理动作后的反馈频率；后者改变动作生成的积分次数。DP仍100次去噪。
- A2A问题解决了吗？找到初始夹爪敏感性的重要证据，改初态后救回表现；原初始化下稳定性仍未解决。
- BAKU完成了吗？已适配、训练、评估并有成功行为，但100%/30%的差异没有完成定位。
- 现在是否复现整篇论文？只完成单任务阶段工作，方法配方/预算不同，没有论文整套分数或延迟结论。
